# Explainable Sleep Stage Classification Using Machine Learning on Physiological Signals from Wearable Devices

*Code repository for a Master's Thesis (TFM), Master's Degree in Artificial Intelligence, Universidad Complutense de Madrid (UCM), 2026.*

## English version

### Project Overview

This repository contains the code developed for the Master's Thesis (TFM) *"Explainable Sleep Stage Classification Using Machine Learning on Physiological Signals from Wearable Devices"*, part of the Master's Degree in Artificial Intelligence at the Complutense University of Madrid (UCM).

The project classifies sleep stages (Wake/Sleep, or more granular 3- and 4-stage scenarios) using a single, low-cost physiological signal: **photoplethysmography (PPG/BVP)**, captured by a wrist-worn wearable (Empatica E4). Rather than relying on deep learning, it follows a classical **feature engineering + machine learning** approach. Around 50 handcrafted features are extracted from the raw PPG signal (waveform morphology, respiratory modulation, statistical/energy features, heart-rate variability, and fractal complexity), and four standard classifiers are trained and compared: **Random Forest, KNN, XGBoost and SVM**.

A central goal of the thesis is **explainability**. Rather than treating the models as black boxes, the project applies and compares four techniques, **LIME, SHAP, Permutation Feature Importance and Partial Dependence Plots (PDP)**, to understand which physiological features drive each prediction, both at the individual and population level.

**Scope**: this is an academic, exploratory prototype. It has **not** been clinically validated and is **not** intended for medical diagnosis or clinical decision-making.

### Dataset

The pipeline is trained and evaluated on the public **[DREAMT dataset](https://physionet.org/content/dreamt/2.1.0/)** (100 subjects, PhysioNet, v2.1.0), using a **patient-level 80/10/10 split** to prevent data leakage between training and test sets. DREAMT is **not included** in this repository; see the instructions below to obtain it.

### Why might this be useful to you?

This repository may be a useful reference if you are working on:
- Sleep stage classification from **PPG-only** signals (no need for full PSG-grade sensors).
- A worked example of applying **LIME, SHAP, Permutation Importance and PDP together** on the same tabular ML pipeline, for comparison.
- A reference implementation for training on the **DREAMT** dataset with a strict **patient-level split**.
- A template for building a **Streamlit clinical-style dashboard** on top of a scikit-learn/XGBoost pipeline.

### Instructions to Replicate the Work

**1. Clone the repository and install dependencies**
```bash
git clone https://github.com/dlandyr/tfm-SleepStagesAI.git
cd tfm-SleepStagesAI
python -m venv venv
source venv/bin/activate    # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

**2. Get the dataset**

This project uses the DREAMT dataset (v2.1.0), hosted on PhysioNet. It is not included in this repository due to its size and PhysioNet's data use agreement.
- Request access and download it from: https://physionet.org/content/dreamt/2.1.0/
- Place the downloaded files under `data/raw/`.
- Adjust paths and parameters in `configs/config.yaml` if needed.

**3. Run the full pipeline**
```bash
python run_pipeline.py
```
This extracts features from `data/raw/`, trains Random Forest, KNN, XGBoost and SVM, evaluates them, and saves results to `outputs/`. Extracted features are cached in `data/processed/`, so this step only needs to be run once.

Alternatively, use `main.py` to run individual stages (feature extraction, training, evaluation, explainability) separately. See `python main.py --help` for available options.

**4. Explore results interactively**
```bash
streamlit run app.py
```
This launches the local dashboard, with dedicated tabs for signal inspection, alerts, and each explainability method (LIME, SHAP, PDP).

*Double-check the exact CLI flags/options of `run_pipeline.py` and `main.py` and adjust the commands above if they differ.*

### Results Summary

| Scenario | Best model | Accuracy |
|---|---|---|
| 2 classes (Wake/Sleep) | XGBoost | 81.28% |
| 3 classes | XGBoost | 75.52% |
| 4 classes | XGBoost | 73.68% |

Across explainability methods, **RIAM_mean, PPI_mean and HCPPG** consistently emerged as the most informative PPG-derived features for sleep stage prediction. Full results, confusion matrices and per-class breakdowns are available in the thesis document and in `outputs/`.

## Versión en español

### Visión general del proyecto

Este repositorio contiene el código desarrollado para el Trabajo de Fin de Máster (TFM) *"Sistema Explicable de Clasificación de Fases del Sueño mediante Aprendizaje Automático sobre Señales Fisiológicas de Dispositivos Wearables"*, del Máster en Inteligencia Artificial de la Universidad Complutense de Madrid (UCM).

El proyecto clasifica las fases del sueño (Vigilia/Sueño, o los escenarios más granulares de 3 y 4 clases) a partir de una única señal fisiológica de bajo coste: la **fotopletismografía (PPG/BVP)**, capturada por un dispositivo wearable de muñeca (Empatica E4). En lugar de recurrir al aprendizaje profundo, sigue un enfoque clásico de **ingeniería de características + aprendizaje automático**. Se extraen unas 50 características de la señal PPG cruda (morfología de la onda, modulación respiratoria, estadísticos y energía, variabilidad del ritmo cardíaco y complejidad fractal), y se entrenan y comparan cuatro clasificadores estándar: **Random Forest, KNN, XGBoost y SVM**.

Uno de los objetivos centrales del TFM es la **explicabilidad**. En vez de tratar los modelos como cajas negras, el proyecto aplica y compara cuatro técnicas, **LIME, SHAP, Permutation Feature Importance y Partial Dependence Plots (PDP)**, para entender qué características fisiológicas impulsan cada predicción, tanto a nivel individual como poblacional.

**Alcance**: este es un prototipo académico y exploratorio. **No** ha sido validado clínicamente y **no** está pensado para diagnóstico médico ni para la toma de decisiones clínicas.

### Dataset

El pipeline se entrena y evalúa sobre el dataset público **[DREAMT](https://physionet.org/content/dreamt/2.1.0/)** (100 sujetos, PhysioNet, v2.1.0), usando una partición **80/10/10 a nivel de paciente** para evitar fuga de información entre los conjuntos de entrenamiento y test. DREAMT **no está incluido** en este repositorio; consulta las instrucciones más abajo para obtenerlo.

### ¿Por qué puede resultarte útil?

Este repositorio puede servir como referencia si estás trabajando en:
- Clasificación de fases del sueño a partir de **PPG únicamente** (sin necesidad de sensores de grado PSG).
- Un ejemplo aplicado de **LIME, SHAP, Permutation Importance y PDP combinados** sobre el mismo pipeline tabular, para comparación.
- Una implementación de referencia para entrenar sobre **DREAMT** con una partición estricta **a nivel de paciente**.
- Una plantilla para construir un **dashboard clínico con Streamlit** sobre un pipeline de scikit-learn/XGBoost.
